How it works

One vote. Continuous execution.

The DAO decides the strategy. Wardex handles every action that follows.

①
Vote on Treasury Policy
DAO passes one proposal: approved strategies, risk thresholds, concentration limits. That's the last vote required.
→
②
Wardex Monitors 24/7
Agent reads live on-chain treasury data via Realms SPL Governance. Tracks native token concentration, idle capital, bear market signals.
→
③
Auto-Execute Within Mandate
When thresholds are met, agent rebalances or deploys yield — within multisig guardrails. Fully non-custodial, no discretionary authority.
